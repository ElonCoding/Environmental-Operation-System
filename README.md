---

Environmental Operation System (OES) is a data-driven decision-support platform designed to analyze historical water-quality observations from monitored idol-immersion ghats in Bhopal (Upper Lake, Lower Lake, Shahpura Lake). It helps civic teams explore measurements, compare them with Central Pollution Control Board (CPCB) criteria, and prepare evidence-backed action briefs.
