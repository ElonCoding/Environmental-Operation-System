# Changelog

All notable changes to the Environmental Operation System (OES) are documented here.

## [1.0.0] - 2026-10-11
### Added
- Complete FastAPI backend with 7-ghat CPCB Class B evaluation.
- High-performance React 19 + Vite + Tailwind CSS dashboard.
- Interactive Recharts visualization for DO and BOD degradation curves.
- Automated Render (`render.yaml`) and Vercel (`vercel.json`) configurations.
- PDF and Executive Officer brief generation service.
