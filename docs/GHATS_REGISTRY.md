# Bhopal Immersion Sites Registry

The platform standardizes monitoring across 7 canonical sites:

1. **Khatlapura Ghat** — Lower Lake (High density, historical priority)
2. **Sheetal Das Ki Bagiya** — Upper Lake (Primary immersion point)
3. **Prempura Ghat** — Upper Lake (Artificial kund diversion active)
4. **Rani Kamlapati / Kamla Park** — Lower Lake spit
5. **Bairagarh (Sant Hirdaram) Kund** — Upper Lake western shore
6. **Shahpura Lake Ghat** — Manisha Market lake front
7. **Hathaikheda Dam Site** — Eastern reservoir
