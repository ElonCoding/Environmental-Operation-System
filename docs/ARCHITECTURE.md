## CPCB Class B Standard (Organized Outdoor Bathing)
1. **Dissolved Oxygen (DO):** ≥ 5.0 mg/L
2. **Biochemical Oxygen Demand (BOD):** ≤ 3.0 mg/L
3. **pH:** 6.5 to 8.5
4. **Fecal Coliform:** ≤ 500 MPN/100ml
